# KegWatch

**NOTE: This respository is under going some reorganization and will be revived soon :)**

*KegWatch is a beer tracking and analytics device that I designed for my own kegerator because I was tired of not knowing how much beer was left in the kegs. My approach offers a unique, non-invasive solution to this common problem - no modifications to beer lines and no electronics inside the kegerator itself. The system works by using linear hall-effect sensors installed on top of the beer tower and magnets placed on the back of your tap handles. KegWatch uses time to estimate how much beer was poured. After a simple calibration process, every pour is logged based on the amount of time the tap handle remains open. This technique has been surprisingly accurate throughout testing.*

*This project is very much in active development and in no way "production" or "release" ready. However, I like to work in the open so if you're interested in this project be sure to follow along!*
